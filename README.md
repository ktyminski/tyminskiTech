# Tyminski Tech

Statyczny landing page przygotowany do automatycznego wdrażania na Vercel.

## Deploy z GitHub do Vercel

1. Zaloguj się do [Vercel](https://vercel.com/new) przez GitHub i wybierz repozytorium `ktyminski/tyminskiTech`.
2. Pozostaw katalog główny jako `./`. Konfiguracja z `vercel.json` automatycznie wskaże folder `dist` jako stronę do publikacji.
3. Kliknij **Deploy**. Kolejne pushe do gałęzi `main` będą publikowane automatycznie; inne gałęzie dostaną adresy podglądowe.

Po pierwszym deployu w ustawieniach projektu Vercel dodaj domenę `tyminski.tech` i ustaw jej rekordy DNS zgodnie z instrukcją Vercela.
